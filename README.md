# Predictive Modeling for Course Demand and Revenue Forecasting on EduPro

## Project Overview

This project analyzes course demand, enrollment patterns, and revenue on the EduPro online learning platform. It uses data analysis, visualizations, and machine learning models to understand course performance and estimate course demand and revenue.

## Objectives

* Analyze users, courses, teachers, and transactions.
* Identify courses with high demand.
* Analyze revenue by course and category.
* Visualize important trends and patterns.
* Build machine learning models to predict course demand and revenue.

## Methodology

1. Data loading and inspection.
2. Data cleaning and validation.
3. Exploratory data analysis.
4. Data visualization.
5. Feature selection and predictive modeling.
6. Model evaluation using MAE, RMSE, and R-squared.

## Expected Outcome

The project provides insights into course demand and revenue patterns that can help an online learning platform understand course performance and support data-driven planning.

## Conclusion

This project combines data analytics and machine learning to explore course demand and revenue forecasting using EduPro platform data.
